## TASK 05 — GRAND LINE GUARDIAN

For this task, I worked on a terminal-based system monitoring tool. The project involved reading information from the `/proc` filesystem and displaying process information such as process IDs, process names, CPU usage, memory usage, and active process counts.

This task helped me understand how Linux exposes system information through the `/proc` filesystem and gave me more experience with Python.

## TASK 07 — DANK MEMER DISCORD BOT

For this task, I worked on a Discord bot and explored how a bot can interact with a database.

I worked with SQLite and implemented concepts such as users, wallets, banks, and cooldown-related data. This task helped me understand database schemas, SQL queries, and how application logic can interact with stored data.

## TASK 08 — THE OHARA ARCHIVE

This task involved creating a React-based movie watchlist application using the TMDB API.

Through this project, I gained experience with React, APIs, fetching external data, and building a web application that interacts with an external service.

## TASK 11 — TIMEFLOW WALLPAPER SYNC

For this task, I created a Python program that reads content from a text file and displays it on the system wallpaper. The wallpaper also contains a live time section and updates whenever the contents of the text file change.

I used Python libraries such as Pillow and watchdog. This task helped me understand file monitoring, image generation, and automating changes based on file modifications.
